**As of 12 September 2026, dassi has not been verified in the Ziniao browser.** This page records how far the check got; it is not an installation guide yet.

## How far did the check get?

In a signed-in Ziniao client we opened **管理 → 应用管理** (Management → App management). The page showed:

> 您的企业信息未完善，暂时无法使用此功能
> (Your company profile is incomplete, so this feature is not available yet.)

So this account could not go on to check how apps are installed there. The home screen also promotes device purchases, but that does not prove every Ziniao user must buy a plan to install dassi.

## If you already have a Ziniao account

1. Check whether the company profile is complete and whether the current member has app-management permission.
2. Check that you have a browser environment that starts normally.
3. Ask your Ziniao admin or support whether the environment allows third-party Chromium extensions, and whether extension side panels and debugger permissions are supported.

A Chromium core alone does not prove dassi's full feature set works. We will update the support status only after a real install, sign-in and a read-only task.

**Please do not buy a Ziniao plan just to install dassi.** If you want to try now, use the [Edge install guide](/edge-install/), which has a verified install record.
