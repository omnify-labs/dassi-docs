---
title: Using projects
description: Keep ongoing work organized in Dassi projects, share saved files across chats, and pick up where you left off.
---

A project keeps an ongoing piece of work together: its goal, files, and saved
progress. Use one for work you expect to return to, such as an outreach campaign,
supplier research, or planning an event. You can work across websites and use
several chats for the same project.

## Create a project

1. Open the Dassi side panel in a chat outside a project.
2. Click **Projects** below the toolbar.
3. Enter a **Project name**.
4. Under **What should this project accomplish?**, describe your goal, requirements,
   and what a finished result should look like.
5. Click **Save chat as project**.

If Dassi is working, wait for the run to finish or stop it before creating or
switching projects.

For example, name a project **Community partnerships** and give it this brief:

> Find 15 potential community partners for our San Francisco event. Save each
> organization's website, why it fits, and a personalized outreach draft. Keep
> the messages as drafts for my review.

The project name now appears below the toolbar. Continue chatting normally:

> Start by researching five candidates and save the results in this project.

If you started the work before creating the project, ask Dassi to save the useful
results, decisions, and attachments from that chat. Creating a project does not
automatically copy every earlier file into it.

## Understand what a project keeps

Think of the project as a work folder inside Dassi. Chats are where you give
instructions and discuss the work; project files carry useful information into
future chats.

| Part | What it is for |
|---|---|
| Project | The shared home for an ongoing goal and its saved work. |
| Chat | A conversation about that work. A project can have several chats. |
| `README.md` | The project brief: what you want to accomplish and the requirements. |
| Other project files | Research, drafts, results, and notes needed to continue. |
| Ledger, when useful | A list or table tracking individual items and their progress, such as which prospects have been researched or have a draft ready. |

Dassi organizes the files to suit your task. You do not need to choose filenames
or maintain a special checkpoint document. You can ask for a particular format
when it helps, such as a table of prospects or one document containing all drafts.

To change the direction of the work, say what changed:

> Focus on nonprofit organizations now. Update the project brief and mark which
> existing candidates still fit.

## Continue in another chat

Expand the project name and click **New chat in project** to start a fresh
conversation with access to the same saved files. You can use one chat for
research and another for reviewing drafts; multiple chats can work in the same
project at the same time.

In the new chat, tell Dassi where to pick up:

> Read the saved project work. Show me which candidates still need research, then
> continue with the next five.

The new chat can read the project files as needed. It does not automatically
include the full transcript of every earlier chat, so save decisions and useful
results in the project when they matter for later work.

## View, update, and download files

1. Click the project name below the toolbar to expand it.
2. Under **Project files**, click a filename to open it.
3. Use **Download** to save a copy of that file to your computer.

Text and images can be previewed in the panel. Download other file types to view
them. Use the refresh button beside the project selector if the list looks out
of date.

To update a file, ask Dassi in the chat:

> Shorten the outreach drafts to under 100 words each and save the revised versions.

## Come back tomorrow or next week

Saved project files survive closing and reopening Chrome. Before leaving, you
can ask:

> Save the current results, what is unfinished, and the next steps in this project.

Let Dassi finish saving. Closing the browser does not keep the work running.

When you return:

1. Open Dassi in the same Chrome profile with the same Dassi account.
2. Expand **Projects**, or the current project name, below the toolbar.
3. Select your project from the dropdown. If it is already selected, use
   **New chat in project** for a fresh conversation.
4. Ask Dassi to read the saved work and continue.

You do not need to keep the original chat or browser tabs open. You may need to
reopen a website or sign in again to continue work there.

Projects are saved locally in that Chrome profile. They do not automatically
sync to another browser or device. Signing into a different Dassi account clears
local project data; uninstalling Dassi or clearing its extension data can also
remove it. Download important files to keep a backup.

## Switch projects or work outside one

Expand the project name and choose another project from the dropdown to open a
chat in it. Choose **Chat outside a project** for a separate task. From there,
you can also create another project.

Leaving a project keeps its files available for later. Deleting a project chat
also keeps the project's saved files. For a one-off question, you can simply
chat outside a project without creating one.
