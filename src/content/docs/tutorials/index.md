title: "Use cases: start with one small task"
---

Choose a task, copy its prompt into Dassi, and review the result. Each page is one job with a copyable prompt and a "check the result" step.

Four of these come with fictional practice pages in English and Chinese; the rest are prompt templates to run in your own accounts. Fictional data is not a customer case study or a compatibility claim for every website. Start with a small batch in an account you are authorized to manage.
