:::note[Start small]
This is a prompt template for a workflow, not a verified case study. Results depend on the site, the page you have open and the model. Review the output before acting on it, and keep anything that changes an account (submit, send, book, buy) for your own hands.
:::

Comparing two chatbots usually means copying both answers into a third window. Dassi reads the two tabs where they already are.

## Before you start

New to Dassi? Follow the [installation guide](/getting-started/installation/) and [model setup guide](/guides/connect-ai-provider/).

Run the same prompt in two tools in two tabs of the same Chrome window (for example ChatGPT and Claude). Leave both answers on screen. Open Dassi on either tab. Decide what "better" means for you before you ask — reply rate, accuracy, tone.

## 1. Compare

```text
Read the latest answer in my ChatGPT tab and the latest answer in my Claude tab. Both were given this prompt: "[the prompt]". My goal is [what better means, e.g. a sales email that gets replies].
Compare them on: fit to the goal, factual accuracy, length, and tone. Give a verdict and 3 specific reasons, quoting from each answer.
```

## 2. Improve the prompt

```text
Write a revised prompt that keeps the strengths of both answers and fixes the weaknesses you found. Explain each change in one line. Don't run it — I'll paste it myself.
```

## Check the result

The quotes in the comparison should appear in the tabs — check one from each. A verdict without your goal in it is generic; if it reads that way, restate the goal and ask again. Dassi doesn't send anything to either tool here.
