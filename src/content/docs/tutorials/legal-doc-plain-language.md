You will still need to read the contract. Dassi tells you which paragraphs to read slowly.

## Before you start

New to Dassi? Follow the [installation guide](/getting-started/installation/) and [model setup guide](/guides/connect-ai-provider/).

Open the document in Chrome (a web page or a PDF opened in the browser). Open Dassi alongside it. Dassi is not a lawyer; use this to prepare questions, not to decide.

## 1. Summarize clause by clause

```text
Go through this document paragraph by paragraph. After each one, give a one-sentence plain-language summary of what it means for me as the [tenant / customer / contractor].
Flag any clause about fees, penalties, termination, automatic renewal, liability or data use, and say why. Quote the exact wording for anything you flag.
```

## 2. Prepare to negotiate

```text
List the 5 clauses I should ask about or negotiate, most important first, with the question I should ask for each. Then draft a short, polite email asking for clarification on the top 2.
```

## Check the result

Read every flagged clause in full yourself — the flag is a prompt to read, not a legal opinion. Check that quoted wording matches the document exactly. If a clause references a schedule or annex that isn't on the page, Dassi hasn't read it; say so in your questions.
