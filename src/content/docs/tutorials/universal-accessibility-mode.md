Browser zoom makes everything bigger, including the parts that were fine. Dassi can change just the body text, just the contrast, or just the animations, and reuse the same settings elsewhere.

## Before you start

New to Dassi? Follow the [installation guide](/getting-started/installation/) and [model setup guide](/guides/connect-ai-provider/).

Open a page you find hard to read in Chrome. Open Dassi alongside it. Know what you want changed — this works best as specific instructions, not "make it accessible".

## 1. Adjust this page

```text
Make this page easier for me to read: switch body text to [a dyslexia-friendly font / a larger sans-serif], increase line spacing to 1.6, change the background to a soft off-white, and stop any animations or autoplaying video.
Only change the article/body text, not the site navigation. Tell me what you changed.
```

## 2. Keep it everywhere

```text
That's right. Save these settings as a persistent script that runs on every site I visit, and call it "reading profile". Tell me how to turn it off for a single site.
```

## Check the result

Scroll the page: headings, links and buttons should still be distinguishable, and forms should still work. Visit one other site and confirm the profile applied and nothing broke. If a site looks wrong, ask Dassi to exclude that domain from the script rather than deleting the profile.
