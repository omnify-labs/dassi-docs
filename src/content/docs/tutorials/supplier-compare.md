## 2. Copy this prompt

Keep the practice page active. Paste this into the Dassi sidebar and send it.

```text
Compare the three quotes on this practice page in an English table: supplier, unit price, currency, MOQ, eligibility for an order of 200, packaging, production time, freight, and open questions. Include the source page link. Flag quotes whose MOQ exceeds 200. Do not treat different packaging as identical, invent freight or taxes, choose a supplier, or place an order.
```

## 3. Review the result

Supplier B has an MOQ above 200. Supplier C has different packaging. These quotes do not establish comparable delivered totals.

If the page cannot be read, ask Dassi to identify missing information before supplying it. Do not ask it to guess.

## 4. Use your own page

Open a relevant business page you are authorized to process. Adapt the product, quantity or language in the prompt. Review the draft or table before proceeding. This use case does not configure background auto-replies or send customer messages automatically.
