先选一个小任务，打开相关网页，再把下面的话复制到 Dassi。第一次先处理 1—3 个页面，结果自己核对。

## 商品资料放进一张表

```text
整理这三个已打开的商品页面：名称、价格、币种、库存状态、来源链接。
每个商品一行。页面没有写的信息标记“未找到”，不要推测。
保留页面原始价格，不换算币种。不下单，不修改网页。
```

我们在比特浏览器中用 Books to Scrape 的三个公开图书页面做过商品整理测试。它是演示网站，不是真实商店业务案例；其他网站需要单独确认读取效果。

## 收到客户官网，先了解对方做什么

```text
看看当前公司的官网，整理：公司做什么、主要产品、明确写出的服务市场、公开联系方式。
每条信息附来源链接。事实和推测分开；没有找到的信息留空。
只整理，不发送邮件，不提交表单。
```

## 评价太多，先找重复出现的问题

```text
整理当前页面可见的商品评价，按大家提到的问题分类。
每一类保留对应原文，并统计本次实际读到的条数。
说明读取范围，不把几条评价当成所有买家的结论。
```

后两个是可以尝试的任务模板，不代表已在你的业务网站上验证。页面无法读取时，让 Dassi 说明原因，不要补编结果。
