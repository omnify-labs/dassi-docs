## dassi 如何处理你的数据

dassi 完全以 Chrome 扩展的形式运行。它没有自己的后端服务器来处理你的浏览数据。

你发送消息时，dassi 会：

1. 读取当前页面内容（文字、结构，有时还有截图）
2. 把这些内容连同你的提示发送给你选择的 AI 模型
3. 接收回复，并在浏览器中执行操作

**你的数据直接从浏览器发往 AI 服务商。** dassi 不会存储、记录或把你的浏览数据转发给任何其他服务。

## dassi 不收集什么

- 浏览历史
- 密码或已保存的凭据
- 信用卡或银行信息
- 当前对话之外的标签页数据
- 你没有让 dassi 读取的页面内容

## 权限

dassi 请求以下 Chrome 权限：

| 权限 | 用途 |
|-----------|----------------|
| **Active tab** | 读取你正在操作的标签页内容 |
| **Side panel** | 显示 dassi 侧栏界面 |
| **Scripting** | 截图并操作页面元素 |
| **Storage** | 保存你的设置、对话历史和记忆 |
| **Identity** | 用 Google 账号登录 |

dassi 只在你主动发送消息或运行技能时访问标签页内容，不会被动监视你的浏览。

## AI 服务商的数据处理

你的提示和页面内容会发送给你选择的 AI 服务商：

- **托管额度** — 请求经由托管 API 网关路由到 Anthropic（Claude）、Google（Gemini）等服务商
- **BYOK（OpenAI）** — 请求用你自己的 API key 直接发往 OpenAI

每个服务商有各自的数据处理和保留政策。关于他们如何处理 API 请求，请查阅所选服务商的隐私政策。

## 本地存储

dassi 在你的浏览器本地保存以下数据：

- **对话历史** — 你的聊天消息和回复
- **记忆** — 你让 dassi 记住的事
- **设置** — 模型选择、API key 和偏好
- **技能** — 你创建的自定义技能

这些数据保存在浏览器的扩展存储中。清除浏览器数据或卸载 dassi 会将其删除。

## 计划审批

在访问新域名或在敏感页面上执行操作之前，dassi 会给出一份计划请你批准。你必须明确批准，dassi 才会继续。这让你对 dassi 的行为拥有完全的可见性和控制。

## 停止 dassi

随时可以停止 dassi：

- 在任意标签页按 `Ctrl+Shift+C`（Mac 上是 `Cmd+Shift+C`）
- 侧栏获得焦点时按 `Esc`
- 点击控制横幅中的 **Stop** 按钮
- 关闭侧栏

被中断时，dassi 会立即停止所有浏览器自动化。
