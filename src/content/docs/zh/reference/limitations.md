dassi 很强大，但有些重要的事它做不到。了解这些限制有助于你获得最好的结果。

## 浏览器限制

### Chrome 内部页面

dassi 无法操作 Chrome 的内置页面：

- `chrome://settings`
- `chrome://extensions`
- `chrome://flags`
- `chrome://history`
- 任何 `chrome://` 开头的页面

这些页面受 Chrome 扩展安全模型的限制。

### 其他扩展的页面

dassi 无法操作其他 Chrome 扩展的弹窗或页面。Chrome 禁止扩展之间通信。

### Chrome 版本

dassi 需要 **Chrome 138 或更高版本**。侧栏 API 及 dassi 依赖的其他功能在旧版本中不可用。

## 内容限制

### 页面上下文

dassi 读取当前标签页可见的内容。它可以滚动获取首屏以下的内容，但单次对话能处理的内容量有实际上限。

### 复杂的 Web 应用

一些高度动态的 Web 应用（比如基于 canvas 的高级编辑器或游戏）内容渲染在标准 DOM 之外，dassi 可能难以稳定地操作。

### iframe 和嵌入内容

取决于网站的安全响应头，dassi 操作跨域 iframe 中内容的能力可能有限。

## 安全边界

### 密码和银行信息

dassi 绝不会输入密码、信用卡号、银行账户信息或其他敏感金融凭据。如果任务需要登录或输入支付信息，dassi 会请你自己完成这一步。

### 验证码

dassi 尊重机器人检测系统（验证码、真人验证），不会尝试绕过或破解。遇到验证码时，dassi 会请你先完成再继续。

### 创建账号

dassi 不会替你创建账号。如果流程需要注册某个服务，dassi 会把你带到注册页，但请你自己完成注册。

## 范围限制

### 标签页组范围

每段 dassi 对话绑定一个 Chrome 标签页组。dassi 只能看到并操作当前组内的标签页，无法访问组外或其他窗口的标签页。

### 不在后台执行

dassi 只在侧栏打开且你正在对话时工作。它不会在后台或按计划运行任务。

### 单一对话

每个标签页组同一时间只处理一段对话。同一组内不能并行多段对话。

## 模型限制

### 上下文窗口

AI 模型有最大上下文窗口——一次能处理的文字量。很长的对话或文字量很大的页面可能让 dassi 跟丢之前的上下文。开始新对话会重置上下文。

### 准确性

dassi 使用的 AI 模型可能出错。重要任务在采取行动前请务必检查 dassi 的工作。dassi 可能会：

- 误读复杂页面上的内容
- 在密集的界面里点错元素
- 生成不准确的摘要或回复
- 误解含糊的指令

### 速度

响应时间取决于你选择的 AI 模型和任务复杂度。有些模型比另一些快——详见[模型与服务商](/zh/guides/connect-ai-provider/)。
