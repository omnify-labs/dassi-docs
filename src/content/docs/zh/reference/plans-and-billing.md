dassi 提供免费档和几种付费选项。所有套餐都包含完整的浏览器自动化能力。

## 套餐

| | Free | BYOK | Starter | Pro | Max |
|---|---|---|---|---|---|
| **价格** | $0 | $10/月 | $25/月 | $100/月 | $300/月 |
| **托管额度** | 一次性 $5 | — | 包含 | 包含 | 包含 |
| **模型** | Gemini 3 Pro、3.5 Flash | OpenAI 模型 | 全部模型 | 全部模型 | 全部模型 |
| **自定义技能** | 是 | 是 | 是 | 是 | 是 |
| **优先支持** | — | — | — | 是 | 是 |

### Free

免费试用 dassi。新账号一次性获得 $5 托管额度——不需要信用卡——可用于 Gemini 3 Pro 和 Gemini 3.5 Flash。适合在选购付费套餐之前先试试。

### BYOK — $10/月

使用你自己的 OpenAI API key。模型用量直接付给 OpenAI，dassi 每月收取 $10 的平台使用费。可用的 OpenAI 模型包括 GPT-5、GPT-5 Mini 和 GPT-5 Nano。

设置步骤见[模型与服务商](/zh/guides/connect-ai-provider/)。

### Starter — $25/月

用托管额度解锁全部托管模型（Claude Sonnet 4.5、Claude Opus 4.6、Gemini 3 Flash、DeepSeek V3.2、GLM 4.7）。不需要 API key。

### Pro — $100/月

更高的额度配给，适合重度使用。包含优先支持。

### Max — $300/月

最高的额度配给，适合自动化需求密集的高级用户和团队。

## 计费周期

可以按月或按年付费。在 **Settings > Plan & Billing** 用 **Monthly / Yearly** 开关对比。选择按年时，每张套餐卡片会把年费换算成「按年计费的每月价格」显示，方便和月付直接比较。年付在所有套餐上最多可省 50%。

上表中的价格是按月计费的价格。年付价格在 Plans 标签中实时显示。

## 用微信支付一次性购买

如果 dassi 的界面语言设为中文，**Settings → Plan & Billing** 里每张套餐卡片上会出现 **微信支付** 按钮。可以用它一次性购买任意档位——不需要连续订阅。

- 选择 **Monthly** 周期并点击 **微信支付**，按月价获得 30 天的使用权。
- 选择 **Yearly** 周期，按年价获得 365 天的使用权。

价格以美元计。Stripe 会在结账时显示等值的人民币。期限结束后使用权自动到期——不会自动续费。已有有效订阅的用户无法进行一次性购买。

## 托管额度

托管额度用于支付 AI 模型的使用成本。你发送的每条消息按以下因素消耗额度：

- 你选择的模型（高级模型每条消息成本更高）
- 任务的复杂度（更长的对话消耗更多额度）
- 截图和页面内容的处理

付费套餐的额度随计费周期每月刷新；Free 档的 $5 是一次性额度，不会刷新。可以在 **Settings > Plan** 查看用量。

## 管理订阅

1. 打开 dassi 侧栏
2. 点击侧栏工具栏的 **⋮**，再点 **Settings**
3. 进入 **Plan**

在这里可以查看当前套餐、额度用量，并管理订阅。
