dassi 是一个浏览器扩展形态的 AI 代理。它常驻在浏览器侧栏里，能看到、理解并操作任何网页，替你完成任务。

## dassi 能做什么

- **看懂页面** — 读取页面内容、理解布局，并截图核对自己的执行结果
- **执行操作** — 点击按钮、填写表单、输入文字、在页面和标签页之间切换
- **串起多步流程** — 跨多个标签页做调研、填申请表、批量提取数据
- **写作与改写** — 起草邮件、总结文章、改写文案、撰写消息
- **搭建小工具** — 直接在网页里生成小面板、图表和交互组件
- **记住上下文** — 跨对话保存关于你和你偏好的信息

## 如何运作

1. **安装** dassi 浏览器扩展（[Chrome](/zh/getting-started/installation/) 或 [Edge](/zh/edge-install/)）
2. **登录** Google 账号，或用邮箱登录
3. **打开侧栏**，开始一段对话
4. **把任务交给 dassi** — 它会规划、执行并核对结果

dassi 可以连接 Claude、Gemini、GPT 等模型。可以直接使用托管额度（不需要 API key），也可以填入自己的 key，见[模型与服务商](/zh/guides/connect-ai-provider/)。

## 隐私优先

dassi 完全在你的浏览器里运行。只有在你发起任务时，网页数据才会发送给你选定的模型服务商。dassi 不会收集浏览历史、密码或个人数据。
