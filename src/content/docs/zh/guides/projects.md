---
title: 使用项目
description: 用 dassi 项目把持续进行的工作组织起来，在多个聊天之间共享保存的文件，并从上次停下的地方继续。
---

一个项目把一件持续进行的工作放在一起：目标、文件和保存的进度。适合你预计会反复回来的工作，比如一次外联活动、供应商调研或活动策划。同一个项目可以跨网站工作，也可以用多个聊天。

## 创建项目

1. 在项目之外的聊天里打开 dassi 侧栏。
2. 点击工具栏下方的 **Projects**。
3. 输入 **Project name**。
4. 在 **What should this project accomplish?** 下描述你的目标、要求，以及完成后的结果应该是什么样。
5. 点击 **Save chat as project**。

如果 dassi 正在工作，先等它跑完或停掉，再创建或切换项目。

比如，把项目命名为 **Community partnerships**，任务说明写：

> 为我们在旧金山的活动找 15 个潜在的社区合作伙伴。保存每个组织的网站、为什么合适，以及一份个性化的外联草稿。消息保留为草稿，等我审阅。

项目名称现在会显示在工具栏下方。照常继续聊天：

> 先调研五个候选，把结果保存到这个项目里。

如果在创建项目之前就已经开始了工作，让 dassi 把那段聊天里有用的结果、决定和附件保存进来。创建项目不会自动把之前的每个文件都复制进去。

## 项目保存了什么

把项目理解成 dassi 里的一个工作文件夹。聊天是你下指令和讨论工作的地方；项目文件把有用的信息带到之后的聊天中。

| 组成 | 用途 |
|---|---|
| 项目 | 一个持续目标及其已保存工作的共享归属。 |
| 聊天 | 关于这项工作的一段对话。一个项目可以有多个聊天。 |
| `README.md` | 项目说明：你想完成什么，以及要求。 |
| 其他项目文件 | 继续工作所需的调研、草稿、结果和笔记。 |
| 台账（需要时） | 跟踪单个条目及其进度的列表或表格，比如哪些潜在客户已经调研过、哪些已有草稿。 |

dassi 会按你的任务组织文件。你不需要选文件名，也不需要维护特殊的检查点文档。有帮助的话可以要求特定格式，比如一张潜在客户表，或一份包含所有草稿的文档。

要改变工作方向，说明什么变了：

> 现在只关注非营利组织。更新项目说明，标出哪些现有候选仍然合适。

## 在另一个聊天里继续

展开项目名称，点击 **New chat in project**，开始一段能访问同样文件的新对话。可以一个聊天做调研，另一个审草稿；多个聊天可以同时在同一个项目里工作。

在新聊天里告诉 dassi 从哪里接着做：

> 读取保存的项目工作。告诉我哪些候选还需要调研，然后继续下五个。

新聊天可以按需读取项目文件。它不会自动包含之前每个聊天的完整记录，所以对后续工作重要的决定和有用结果，要保存到项目里。

## 查看、更新和下载文件

1. 点击工具栏下方的项目名称展开。
2. 在 **Project files** 下点击文件名打开。
3. 用 **Download** 把该文件的副本保存到电脑。

文本和图片可以在面板中预览。其他类型的文件下载后查看。如果列表看起来过期了，用项目选择器旁边的刷新按钮。

要更新文件，在聊天里让 dassi 做：

> 把外联草稿都缩短到 100 字以内，保存修改后的版本。

## 明天或下周再回来

保存的项目文件在关闭并重新打开 Chrome 后仍然存在。离开之前可以说：

> 把当前结果、未完成的部分和下一步保存到这个项目里。

让 dassi 保存完。关闭浏览器不会让工作继续运行。

回来时：

1. 在同一个 Chrome 配置文件、同一个 dassi 账号下打开 dassi。
2. 展开工具栏下方的 **Projects** 或当前项目名称。
3. 从下拉菜单选择你的项目。如果已经选中，用 **New chat in project** 开一段新对话。
4. 让 dassi 读取保存的工作并继续。

不需要保留原来的聊天或浏览器标签页。要在某个网站上继续工作，可能需要重新打开或重新登录。

项目保存在该 Chrome 配置文件的本地。不会自动同步到另一个浏览器或设备。登录另一个 dassi 账号会清除本地项目数据；卸载 dassi 或清除其扩展数据也可能删除。重要文件请下载备份。

## 切换项目，或在项目之外工作

展开项目名称，从下拉菜单选择另一个项目，即可在其中打开聊天。选择 **Chat outside a project** 处理独立任务。从那里也可以再创建一个项目。

离开项目后它的文件仍可在之后使用。删除项目聊天也会保留项目已保存的文件。一次性的问题可以直接在项目外聊天，不用创建项目。
