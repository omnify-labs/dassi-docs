本页用一个完整的例子展示 dassi 在实际中是怎么工作的。

## 示例：起草邮件回复

假设你收到一封邮件，想让 dassi 帮忙回复。

### 第 1 步：打开邮箱

在 Chrome 中打开你的邮箱（Gmail、Outlook 等）。

### 第 2 步：打开 dassi 侧栏

点击工具栏上的 **dassi 图标**，或按 `Alt+Shift+D`。

### 第 3 步：让 dassi 帮忙

输入类似这样的提示：

```
读这封邮件，起草一封得体的回复。
接受会议邀请，并建议改到
周三下午 2 点。
```

### 第 4 步：看 dassi 工作

dassi 会：
1. 读取屏幕上的邮件内容
2. 截图以理解页面布局
3. 按你的要求起草回复
4. 在侧栏里展示草稿

以上每一步都会出现在回复的**活动区域**——展开就能看到 dassi 具体做了什么。

### 第 5 步：检查并调整

可以让 dassi 修改草稿：

```
改得随意一点，再短一些
```

满意之后，让 dassi 把它填进去：

```
把这段回复输入到邮件编辑框并发送
```

dassi 会先给出执行计划——批准后，它会把回复填进输入框。

## 写好提示的技巧

- **具体一点** — 「写一封礼貌的婉拒，说明我那周没空」比「回复这封邮件」效果好
- **给上下文** — 告诉 dassi 你的角色、语气偏好或限制条件
- **多轮调整** — 让 dassi 调整语气、长度或内容
- **用自然语言** — 像跟同事说话一样跟 dassi 说

## 更多可以尝试的

**跨多个网站调研：**
```
比较 Notion、Coda 和 Confluence 的价格。
在新标签页里分别打开各自官网，做一张对比表。
```

**自动录入数据：**
```
读取这个表格里的数据，
把每一行填到下一个标签页的表单里
```

**导航并修改设置：**
```
打开我的 GitHub 通知设置，
关闭 pull request review 的邮件通知
```

**总结与提取：**
```
读这篇 10 页的文章，给我 5 个关键要点
```

**生成可视化：**
```
读取本页的销售数据，
做一个显示每月趋势的交互式柱状图
```
