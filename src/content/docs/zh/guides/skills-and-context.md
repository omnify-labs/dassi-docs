---
title: 技能与上下文
description: 用技能教 dassi 可复用的工作流，用上下文文件提供背景知识，用记忆保存偏好。
---

dassi 通过三套机制了解你和你的工作流：**技能**、**上下文文件**和**记忆**。三者都用自然语言管理——告诉 dassi 你想要什么就行。

## 技能

技能是 dassi 保存下来、之后可以再次运行的指令集。可以把它理解成带名字的已保存提示。

### 创建技能

让 dassi 把一个工作流保存为技能：

```
把这个保存为技能，叫 "weekly-report"。
当我要周报时，读取我所有打开的标签页，
把要点总结成一份 markdown 报告，
分为 Highlights、Action Items 和 Metrics 三个部分。
```

dassi 会为你创建并保存这个技能。

### 运行技能

按名字让 dassi 运行技能：

```
运行 weekly-report 技能
```

或者自然地提到它：

```
生成我的周报
```

dassi 会自动把你的请求匹配到已安装的技能。

### 管理技能

技能可以通过对话管理：

- **列出技能** — 「我安装了哪些技能？」
- **查看技能** — 「给我看 weekly-report 技能」
- **更新技能** — 「更新 weekly-report 技能，再加一个时间线部分」
- **删除技能** — 「删掉 weekly-report 技能」

### 从 URL 安装技能

如果有人分享了技能文件，让 dassi 安装即可：

```
从 https://example.com/skills/my-skill/SKILL.md 安装技能
```

也可以在设置界面导入：打开 **Settings → Skills**，点击 **Import Skill**，粘贴 URL，再点击 **Import**。

### 导入技能包

有些技能以 `.zip` 包的形式分发——根目录是 `SKILL.md`，另外可选 `references/` 和 `assets/` 子目录放辅助文件。需要示例文档、模板或查询表的技能会用这种方式。

安装技能包：

1. 打开 **Settings**（侧栏工具栏的 **⋮** 菜单 → **Settings**），进入 **Skills** 标签。
2. 点击 **Import Skill**。
3. 点击 **Choose .zip file…**，选择技能包。

dassi 会校验压缩包、安装技能，并让其中的参考文件在执行时可读。包压缩后不能超过 10 MB；图片、字体等二进制文件会自动跳过——只保存文本文件。

### 技能命名

技能用 kebab-case 命名，如 `weekly-report`、`pdf-processing` 或 `code-review`。创建技能时 dassi 会自动命名，如果你想指定名字，直接告诉它。

## 上下文文件

上下文文件为 dassi 提供对话中可以参考的背景信息。技能是要执行的指令，而上下文文件是供 dassi 取用的知识。

适合放进上下文文件的内容：

- 你的角色和职责
- 公司特有的术语
- 偏好的写作风格或语气
- 项目细节和约定

### 管理上下文文件

让 dassi 保存上下文：

```
把这个保存为上下文：我在 Acme Corp 做产品经理。
我们的主要产品是一个 B2B SaaS 平台。对客户沟通用正式语气，
内部沟通用随意语气。
```

也可以通过提问来列出、查看、更新或删除上下文文件：

```
我有哪些上下文文件？
```

```
更新我的公司上下文，加上我们最近发布了一个移动端应用
```

## 记忆

dassi 可以跨对话记住你告诉它的事：

```
记住我喜欢用要点列表，不喜欢大段文字
```

dassi 会保存下来，并在之后的对话中应用。

### 记忆的工作原理

- 记忆在你账号下的所有对话之间持续有效
- dassi 把记忆保存在扩展本地
- 要忘掉某件事，告诉 dassi：「忘掉我喜欢要点列表这件事」

### 什么该存进记忆

- 个人偏好（写作语气、排版风格）
- 常用信息（你的名字、职位、团队）
- 工作流偏好（你希望任务怎么组织）

## 技能、上下文、记忆的区别

| | 技能 | 上下文文件 | 记忆 |
|---|---|---|---|
| **用途** | 可复用的工作流 | 背景知识 | 简短偏好 |
| **例子** | 「用 3 条要点总结页面」 | 「公司信息和术语」 | 「我偏好正式语气」 |
| **触发方式** | 让 dassi 运行它 | dassi 自动读取 | dassi 自动应用 |
| **适合** | 重复性任务 | 参考资料 | 不断变化的偏好 |
