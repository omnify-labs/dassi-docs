dassi 是一个完整的浏览器自动化代理。它和你一样操作网页——读取内容、点击元素、填写表单、在页面之间跳转。

## dassi 能自动化什么

### 读取页面

dassi 能读懂任何网页：

- **整页内容** — 读取文字、标题、链接和结构
- **交互元素** — 识别按钮、输入框、下拉菜单等控件
- **截图** — 拍下页面快照，用来核对结果和理解复杂布局

### 导航

- **打开 URL** — 访问任意网站
- **前进/后退** — 在浏览历史中移动
- **打开新标签页** — dassi 可以打开多个标签页并在其间切换
- **关闭标签页** — 完成后清理

dassi 打开的所有标签页都会归入一个 Chrome 标签页组，让工作区保持整洁。

### 点击与交互

- **点击按钮和链接** — dassi 通过角色、文字和位置识别元素
- **悬停** — 触发下拉菜单和提示
- **右键** — 打开上下文菜单
- **双击** — 选中文字等双击操作
- **拖放** — 在位置之间移动元素
- **滚动** — 向任意方向浏览长页面

### 填写表单

- **文本输入** — 往任意文本框里输入
- **下拉菜单** — 从下拉列表中选择
- **复选框和开关** — 勾选或取消
- **文件上传** — 往上传字段里附加文件
- **复杂表单** — 处理跨页面的多步表单

### 键盘操作

dassi 可以像你一样按快捷键：

- 单键：`Enter`、`Tab`、`Escape`、`Backspace`
- 组合键：`Ctrl+A`、`Ctrl+C`、`Ctrl+V`、`Cmd+Z`
- 导航键：方向键、`Home`、`End`、`Page Up`、`Page Down`

### 执行 JavaScript

对于高级任务，dassi 可以在页面里运行 JavaScript，用来：

- 读取 HTML 里不可见的数据
- 操作复杂的 Web 应用
- 生成交互式面板和可视化
- 把自定义工具直接注入页面

### 截图

dassi 在工作全程都会截图，用来：

- 理解视觉布局
- 核对操作是否正确完成
- 操作基于坐标的界面
- 让你看到它看到的东西

## 多标签页工作流

dassi 可以同时在多个标签页上工作。例如：

```
在不同标签页里打开 Amazon、eBay 和 Best Buy。
分别搜索「Sony WH-1000XM5 耳机」，
做一张价格对比表。
```

所有标签页都在同一个 Chrome 标签页组里，dassi 可以按需切换。

### 自动清理标签页

任务完成后，dassi 会自动关闭过程中打开的中间标签页——比如搜索结果页，或调研时访问的参考网站。只有包含最终结果的标签页会保留。

这样浏览器能保持整洁，你不用手动关掉多余的标签页。

## 应用原生集成

对某些应用，dassi 使用原生集成，而不是直接在界面上点击。这更可靠——不受界面改版影响，并且通过应用自己的内部流程完成操作。

### Gmail

在 Gmail 上，dassi 可以通过 Gmail 自己的消息管道发送邮件，而不是在撰写窗口里模拟点击。邮件会正常出现在已发送文件夹里，和你自己发的邮件完全一样。

自然地说就行：

```
给 alice@example.com 发邮件，告诉她 Q1 报告已经准备好了。主题：Q1 Report。
```

发送前 dassi 会确认你的意图。支持收件人（`to`、`cc`、`bcc`）、主题，以及纯文本或简单 HTML 正文。

## 计划审批

在访问新域名或在敏感页面上执行操作之前，dassi 会给出一份计划，显示：

- 它将访问哪些网站
- 它将执行哪些步骤

你必须批准计划，dassi 才会继续。这让你完全掌控 dassi 的行为。

## 限制

dassi 无法自动化某些页面：

- **Chrome 内部页面** — `chrome://settings`、`chrome://extensions` 等 Chrome 内置页面无法自动化
- **其他扩展** — dassi 无法操作其他 Chrome 扩展的弹窗或页面
- **验证码** — dassi 尊重机器人检测系统，不会尝试绕过
- **银行凭据** — dassi 绝不会替你输入密码、信用卡号或银行信息

更多细节见[已知限制](/zh/reference/limitations/)。
