---
title: 定时任务
description: 设置每天自动运行的重复任务——即使你不在看着，dassi 也会替你完成。
---

定时任务可以让 dassi 每天在指定时间、指定网站上替你做某件事。任务确认之后，无论侧栏是否打开都会运行。

## 什么时候用定时任务

定时任务适合你平时每天在固定时间手动做的事：

- 每天早上 9:00 给 LinkedIn 上过生日的联系人送祝福
- 8:30 获取 Gmail 未读邮件的摘要
- 每天傍晚查看 X 的首页时间线并互动

重复的部分交给 dassi，你只需要看结果。

## 创建定时任务

打开 dassi 侧栏，描述你想重复的任务。包含三个要素：**时间**、**网站**和**要做什么**。

```
每天早上 9:00，打开 LinkedIn，给今天过生日的联系人送上祝福。
```

```
每天 8:30，打开 Gmail，总结我今天的未读邮件。
```

```
每天傍晚 18:00，打开我的 X 首页时间线，给前 3 条帖子点赞。
```

dassi 会准备好任务，并在激活前显示一张确认卡片。

## 确认任务

描述完任务后，侧栏会出现一张确认卡片，显示目标网站、时间和时区，以及将要运行的准确指令。

请仔细阅读。卡片会说明：只要 Chrome 开着，dassi 每天都会在这个时间用你的账号执行操作，即使侧栏是关闭的。

点击 **Enable daily task** 激活。点击 **Cancel** 则放弃且不保存。

## 管理定时任务

打开 dassi 的 **Options** 页面（侧栏工具栏的 **⋮** 菜单 → **Settings**），进入 **Automations** 标签。这里列出了所有定时任务及其网站、时间和当前状态。

在列表中可以：

- **Enable** — 确认一个已创建但尚未激活的任务
- **Pause** — 暂停任务但不删除
- **Resume** — 恢复已暂停的任务
- **Delete** — 永久删除任务

回到这个标签页时列表会自动刷新，所以你在侧栏里做的修改总能在这里看到。

## 任务运行时会发生什么

dassi 会在新标签页打开目标网站，按你的指令执行，和手动发起的任务一样。如果那一刻侧栏是打开的，你会看到活动日志实时更新。

任务完成后，dassi 会发送桌面通知。

如果任务连续失败三次，dassi 会自动暂停它，并在 Automations 标签中标为 **Error**。检查任务描述，修复导致失败的原因（比如网站登录过期），然后点击 **Resume** 重新启动。

## 限制

- **Chrome 必须开着。** Chrome 没运行时定时任务不会执行。如果到点时 Chrome 是关闭的，你重新打开 Chrome 后 dassi 会很快补跑。
- **在你的设备上运行。** 任务在你的浏览器里运行，使用你已登录的会话和 cookie——dassi 不是托管在云端的。如果网站登录过期，任务会失败。
- **每天一次。** 每个定时任务每天在指定时间触发一次。不支持按分钟或按小时调度。
- **需要时区。** 在提示里写明时区（「9:00 Eastern」「17:00 Europe/London」），dassi 才能正确安排。如果没写，dassi 会按浏览器的本地时区推断。
