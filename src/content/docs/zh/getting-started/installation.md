dassi 是一个 Chrome 扩展，安装不到一分钟。

## 要求

- **Google Chrome** 138 或更高版本
- 一个用于登录的 **Google 账号**

开始使用不需要 API key——dassi 自带托管额度。

## 从 Chrome 应用商店安装

1. 打开 [dassi 的 Chrome 应用商店页面](https://chromewebstore.google.com/detail/dassi-ai-browser-agent/bjcngahpcjeililljmfegmlanlpgibdi)
2. 点击 **添加至 Chrome**
3. 在弹窗中确认安装

## 首次设置

安装完成后，dassi 会打开一个简短的引导流程：

1. **欢迎** — dassi 做自我介绍
2. **找到扩展** — 在 Chrome 工具栏找到扩展图标
3. **固定扩展** — 把 dassi 固定到工具栏，方便随时打开
4. **开始使用** — 打开 dassi，开始第一段对话

## 固定扩展

为了方便打开，把 dassi 固定到工具栏：

1. 点击 Chrome 工具栏上的 **拼图图标**（扩展程序）
2. 在列表中找到 **dassi**
3. 点击 dassi 旁边的 **图钉图标**

## 登录

第一次打开侧栏时，会看到 **Sign in with Google** 按钮。登录后即可激活账号并获得托管额度。

## 下一步

登录后就可以开始了。按照[快速上手](/zh/getting-started/quick-start/)完成第一个任务。
