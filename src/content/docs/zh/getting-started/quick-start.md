本页带你第一次使用 dassi。

## 前提

- 已在 Chrome 中[安装](/zh/getting-started/installation/) dassi
- 已用 Google 账号登录

## 打开侧栏

点击 Chrome 工具栏上的 **dassi 图标**，或按 `Alt+Shift+D` 打开侧栏。你会看到一个聊天界面，以及针对当前页面的建议操作。

## 试试第一个任务

打开任意网页，试试下面任意一条：

**总结页面：**
```
用 3 条要点总结这个页面
```

**起草邮件回复：**
```
读这封邮件，起草一封得体的回复
```

**填写表单：**
```
用我的名字 John Smith、邮箱 john@example.com 填写这个表单
```

**跨标签页调研：**
```
找到这个商品在 Amazon 上的价格，
再和 eBay 上的对比一下
```

dassi 会读取当前页面、规划步骤，然后执行。工作过程中每一步都会显示在侧栏里。

## 你会看到什么

dassi 工作时，侧栏会显示：

- **活动步骤** — dassi 的每个动作（导航、读取、点击）都是一个可展开的步骤，可以查看细节
- **视觉提示** — dassi 正在控制的标签页会显示发光的边框
- **最终回复** — dassi 的答案，或已完成工作的确认

随时可以点击 **Stop** 中断 dassi。
