用一小批邮件看看 dassi 能不能用你的口吻准备出有用的回复。发送前由你检查保存的草稿。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开目标 Gmail 账号，旁边打开 dassi。选三个会话，或一个界限清楚的收件箱范围。简短描述你偏好的语气，以及回复需要用到的事实。Gmail 的[回复指南](https://support.google.com/mail/answer/9259856?hl=zh-Hans)介绍了底层的回复界面。

## 准备草稿

```text
在我打开的这个 Gmail 账号里，查看[选定的三个会话 / 收件箱最近三个未读会话]。
每个会话读到能理解最新请求为止。我偏好的语气是[语气]。回复可用的事实：[事实]。

为每个会话准备一封简洁的回复，发给正确的收件人。不要编造日期、价格、承诺或个人信息。如果回复需要缺失的信息，把问题列给我，不要猜。

先检查是否已有草稿。不要覆盖它，也不要在未询问的情况下创建另一份。新回复只保存为草稿；不要发送、归档、删除、退订或改标签。除非我明确要求，否则不要选「全部回复」。

确认每份草稿已保存且可以重新打开。返回会话主题、收件人、草稿状态、来源链接（如有）以及需要我解决的问题。然后停下等我检查。
```

## 检查结果

逐个打开草稿，检查收件人、上下文、事实陈述和语气。聊天里显示的回复不等于已保存的 Gmail 草稿。如果没有保存的草稿，把该项标为未完成，先解决阻碍再重试。

打开未读邮件可能会把它们标为已读。如果需要保留未读状态，开始前把这个要求写进去，事后再核对。

这是一个审核流程，不是无人值守的收件箱自动回复。如果中途被打断，保存结果列表，下次运行时先检查已有草稿。
