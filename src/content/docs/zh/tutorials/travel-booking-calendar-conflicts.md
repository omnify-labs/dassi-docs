订票网站知道你的日期；你的日历知道你的会议。在 dassi 把两边都读一遍之前，谁也不知道对方的事。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开订票页，选好你考虑的日期。在另一个标签页打开日历，显示那个月。在订票标签页上打开 dassi。

## 1. 找冲突

```text
我在考虑按本页显示的 [日期] 出行。查看我日历标签页里这些日期前后各加一天的范围，列出每个事件及时间。标出哪些和出行日冲突、哪些可以挪（没有其他参与者）、哪些看起来是固定的。
只读取——不要在任何标签页预订、锁定或改动任何东西。
```

## 2. 挑更好的日期

```text
考虑到这些冲突，在 [时间窗口] 内建议最多 3 个同样长度、避开固定事件的备选日期段。每个都说明还需要挪动什么。
```

## 检查结果

自己在日历里打开冲突的事件；全天事件和其他时区的事件是读取最容易出错的地方。「可以挪」只是按参与者人数判断的——你比它清楚。不应该订任何东西；订票页面应该还停在搜索步骤。
