:::note[先从小范围开始]
这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

读代码示例和运行它通常是两个窗口。对 JavaScript 和简单的 HTTP 示例，dassi 可以直接在示例下面运行。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开文档页，滚动到你想试的示例。旁边打开 dassi。这对浏览器里能跑的代码有效（JavaScript、对公开 API 的 `fetch` 调用）。服务端语言需要你自己的运行环境；让 dassi 改写示例，而不是运行它。

## 1. 运行示例

```text
把「[标题]」下面的代码示例变成可以在本页运行的：加一个可编辑的代码框、一个 Run 按钮，和一个显示输出或错误的区域。
在我粘贴 API key 之前，不要调用任何需要 key 的端点。运行前先告诉我这个示例做什么。
```

## 2. 改一改

```text
把示例改成用 [我的端点 / 参数]，再运行一次，告诉我输出有什么不同。然后把最终版本以代码块给我，方便复制。
```

## 检查结果

确认输出和文档说的一致。如果 dassi 猜了某个值（ID、日期），检查那个猜测。这个 playground 只在本次页面加载期间存在——离开前把能用的代码复制走。
