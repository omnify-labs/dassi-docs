一个 40 分钟的演讲大概有六个观点。dassi 读字幕，给你这六个，每个附上可以跳回去的时间戳。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开 YouTube 视频，确认有字幕可用（视频下方 **…** → **显示转录稿**）。旁边打开 dassi。

## 1. 给视频列提纲

```text
打开这个视频的转录稿，整理成分节结构。每一节给出开始的时间戳（mm:ss）、一个标题和 2–4 条要点。每节包含一句简短的原话引述。
只用转录稿里说的内容；不要添加背景信息。
```

## 2. 提取要做的事

```text
从这些笔记里，列出演讲者给出的所有具体建议或行动项，各附时间戳。然后把整份笔记以 Markdown 给我，方便粘贴到我的笔记里。
```

## 检查结果

点两个时间戳，确认视频跳到了对应的话题。自动生成的字幕会拼错人名和产品名，分享笔记前检查专有名词。如果没有字幕，dassi 读不了音频——它会告诉你，而不是猜。
