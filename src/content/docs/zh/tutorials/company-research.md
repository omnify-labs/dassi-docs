客户发来官网，先整理哪些信息。第一次先用下面的练习资料跑一个小任务，再换成你自己的页面。

## 1. 准备页面

[打开练习资料](/practice/company-research-zh.html)。资料均为虚构，不含真实客户信息。

![客户发来官网，先整理哪些信息：中文练习页面](/images/tutorials/company-research-zh.jpg)

截图展示的是任务输入资料，不是 Dassi 的运行结果。

还没安装？先看[Edge 安装图解](/zh/edge-install/)或[Chrome 安装指南](/getting-started/installation/)。打开 Dassi 侧边栏并完成登录；如果提示额度或模型配置，按[模型设置指南](/guides/connect-ai-provider/)完成设置。

## 2. 复制这段 prompt

保持练习页面为当前标签页，把下面的内容粘贴到 Dassi 并发送。

```text
只读取当前练习公司资料，用中文整理公司做什么、主要产品、明确服务的市场、公开联系渠道和来源链接。将页面事实与推测分开。我们卖保温杯，请提出一个值得进一步核实的匹配点，但不要断言对方有采购需求。采购负责人、预算和计划未公开就标记未找到。不搜集私人联系方式，不发送消息或提交表单。
```

## 3. 核对结果

英国和爱尔兰是页面写出的市场；“可能适合保温杯”只是待验证的推测，不代表采购意向。

若页面打不开或读取不完整，让 Dassi 说明缺少哪些资料，再补充；不要让它猜测。

## 4. 换成你的业务

打开你有权处理的相关业务页面，修改 prompt 中的产品、数量或语言。先检查一次草稿或表格，再决定下一步。这篇教程不会设置后台自动回复，也不会自动发送客户消息。
