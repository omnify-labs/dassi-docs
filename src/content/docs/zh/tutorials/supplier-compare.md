把几家供应商放进一张对比表。第一次先用下面的练习资料跑一个小任务，再换成你自己的页面。

## 1. 准备页面

[打开练习资料](/practice/supplier-compare-zh.html)。资料均为虚构，不含真实客户信息。

![把几家供应商放进一张对比表：中文练习页面](/images/tutorials/supplier-compare-zh.jpg)

截图展示的是任务输入资料，不是 Dassi 的运行结果。

还没安装？先看[Edge 安装图解](/zh/edge-install/)或[Chrome 安装指南](/zh/getting-started/installation/)。打开 Dassi 侧边栏并完成登录；如果提示额度或模型配置，按[模型设置指南](/zh/guides/connect-ai-provider/)完成设置。

## 2. 复制这段 prompt

保持练习页面为当前标签页，把下面的内容粘贴到 Dassi 并发送。

```text
把当前练习页的三家报价整理为中文表格：供应商、单价、币种、起订量、是否满足采购 200 个的要求、包装、备货时间、运费、待确认项。保留来源页面链接。不要把不满足起订量的报价当作可直接购买；不把不同包装当成相同规格，不自行补运费或税费。最后列出下一步要问的问题，不替我选定供应商或下单。
```

## 3. 核对结果

供应商 B 的起订量不满足 200 个采购需求；C 的礼盒包装不同。资料不足以直接比较到门总价。

若页面打不开或读取不完整，让 Dassi 说明缺少哪些资料，再补充；不要让它猜测。

## 4. 换成你的业务

打开你有权处理的相关业务页面，修改 prompt 中的产品、数量或语言。先检查一次草稿或表格，再决定下一步。这一页不会设置后台自动回复，也不会自动发送客户消息。
