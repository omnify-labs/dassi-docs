:::note[先从小范围开始]
这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

记账应用要你导出 CSV 或者交出登录信息。dassi 直接读你已登录页面上的交易表，除了你让它读的文字，什么都不会离开浏览器。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里登录网银，打开一个账户一个月的交易列表。旁边打开 dassi。如果你已经有一套类别，准备好一个简短的列表（比如：餐饮、交通、订阅、外食、其他）。

## 1. 给一个月分类

```text
读取本页可见的交易。把每一笔归入下面这些类别中的一个：[你的类别]。商户名称不明确时用「不确定」。
给我：带类别的交易表、每个类别的合计，以及看起来像定期订阅的交易列表和金额。
只读取。不要点进交易、不要下载对账单、不要改任何设置。
```

## 2. 处理不确定的

```text
「不确定」的那些交易，正确类别是：[商户 → 类别，…]。重新计算合计，并用一张简单的柱状图显示分布。
```

## 检查结果

把类别合计和账户当月的对账单总额比一下——应该能对上。网银页面上的商户名经常被截断，所以「不确定」列表要你自己看，别让 dassi 猜。银行那边不应该有任何改动；如果 dassi 报告它除了滚动之外还点了什么，停下来检查。
