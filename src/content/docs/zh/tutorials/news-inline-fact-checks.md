这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

文章里的大多数说法没被核查，不是因为难查，而是查就得离开页面。dassi 可以在其他标签页打开来源，再回来报告。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开文章。旁边打开 dassi。dassi 会打开新标签页查资料；它会请你批准要访问的网站。

## 1. 列出说法

```text
读这篇文章，列出每一条可以对照来源核查的说法：数字、日期、引语、「第一 / 最大 / 唯一」这类表述。编号。把它们和观点性表述分开。先不要核查。
```

## 2. 核查最重要的几条

```text
核查第 [1、3、5] 条。每条找一个一手来源（官方统计、原始报告、被引用者本人的声明），给出链接，并评级：已证实 / 部分属实——说明缺了什么 / 无法核实。把来源的准确数字和文章的数字并排引用。
```

## 检查结果

打开 dassi 引用的来源，确认数字在那里——链接里没有那个数字是最常见的失败。「无法核实」是可以接受的答案；没有来源却自信地评级则不行。dassi 的评级是你自己判断的起点，不是结论。
