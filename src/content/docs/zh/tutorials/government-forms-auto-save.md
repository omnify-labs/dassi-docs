:::note[先从小范围开始]
这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

政务门户、签证申请、资助表格，二十分钟就超时，然后忘掉一切。dassi 可以边填边留一份副本，之后放回去。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

开始输入之前先在 Chrome 里打开表单。旁边打开 dassi。dassi 只把检查点保存在你的浏览器里；表单网站看不到。

## 1. 开始记检查点

```text
我要开始填这个表单，网站可能会超时。在我填写的过程中记录本页每个字段的值，并保留一个可以恢复的检查点。检查点设好后告诉我，并在我点 Next 之前提醒我再要一个新检查点。
不要提交、不要点 Next、不要自己改任何字段。
```

## 2. 刷新后恢复

```text
页面刷新了，字段都空了。从最后一个检查点恢复每个字段，然后列出你恢复了什么、有什么恢复不了（比如文件上传，或选项变了的下拉菜单）。
```

## 检查结果

恢复之后滚动整页：文件上传和验证码类检查永远恢复不了，下拉选项有时会在两次会话之间变化。检查点是按页的——多步表单每一步都要重新要一个。它是安全网，不能替代在超时前填完。
