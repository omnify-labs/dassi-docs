客户问价格，先写一版回复。第一次先用下面的练习资料跑一个小任务，再换成你自己的页面。

## 1. 准备页面

[打开练习资料](/practice/price-reply-zh.html)。资料均为虚构，不含真实客户信息。

![客户问价格，先写一版回复：中文练习页面](/images/tutorials/price-reply-zh.jpg)

截图展示的是任务输入资料，不是 Dassi 的运行结果。

还没安装？先看[Edge 安装图解](/zh/edge-install/)或[Chrome 安装指南](/getting-started/installation/)。打开 Dassi 侧边栏并完成登录；如果提示额度或模型配置，按[模型设置指南](/guides/connect-ai-provider/)完成设置。

## 2. 复制这段 prompt

保持练习页面为当前标签页，把下面的内容粘贴到 Dassi 并发送。

```text
只读取当前练习页面的客户消息和已确认资料，起草一段简短、自然的英文回复，并附中文说明。说明商品小计，不把它说成到门总价；区分备货时间和运输时间。询问邮编和是否需要定制包装。未知费用明确待确认，不承诺折扣或到货日期。只在侧边栏显示草稿，不发送、不填写任何表单。
```

## 3. 核对结果

检查商品小计是否为 USD 960，是否把运费留作待确认；12 个工作日是备货时间。

若页面打不开或读取不完整，让 Dassi 说明缺少哪些资料，再补充；不要让它猜测。

## 4. 换成你的业务

打开你有权处理的相关业务页面，修改 prompt 中的产品、数量或语言。先检查一次草稿或表格，再决定下一步。这篇教程不会设置后台自动回复，也不会自动发送客户消息。
