合同你还是得自己读。dassi 告诉你哪几段要慢慢读。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开文件（网页，或在浏览器里打开的 PDF）。旁边打开 dassi。dassi 不是律师；用它来准备问题，不是做决定。

## 1. 逐条摘要

```text
逐段过一遍这份文件。每一段之后，用一句大白话说明它对我作为 [租客 / 客户 / 承包方] 意味着什么。
凡是关于费用、罚金、终止、自动续约、责任或数据使用的条款都标出来，并说明原因。标出的内容引用原文措辞。
```

## 2. 准备谈判

```text
列出我应该询问或谈判的 5 条，最重要的在前，每条附上我该问的问题。然后起草一封简短礼貌的邮件，就前 2 条请对方澄清。
```

## 检查结果

每一条被标出的条款都要自己完整读一遍——标记是提醒你读，不是法律意见。检查引用的措辞和文件完全一致。如果某条款引用了不在页面上的附表或附件，dassi 没读到它；在你的问题里说明这一点。
