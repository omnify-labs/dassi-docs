政府网站或供应商网站上的长表格，通常意味着复制、粘贴、清理、画图。dassi 可以就地读取表格，把控件直接加到页面上。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开带表格的页面，滚动到表头可见。旁边打开 dassi。如果页面有多个表格，想好你指的是哪个，用标题或第一列描述它。

## 1. 让表格可交互

```text
看「[标题]」下面的表格。给每个列标题加排序按钮，在表格上方给 [列名] 列加一个筛选框。
在页面上直接做；不要改底层数据，不要提交任何东西。告诉我你检测到的列类型（文字、数字、日期）。
```

## 2. 问它一个问题

```text
现在在表格下方用柱状图显示按 [列名] 的合计，并高亮 [列名] 超过 [阈值] 的行。
```

## 检查结果

按一个数字列排序，肉眼看一下第一行和最后一行；类型检测错误（数字被当成文字）会在这里暴露。图表合计应该和你手动加两三组的结果一致。刷新页面会清掉 dassi 加的一切——这是视图，不是编辑。
