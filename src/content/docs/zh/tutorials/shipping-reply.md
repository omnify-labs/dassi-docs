客户催物流，怎么解释当前进度。第一次先用下面的练习资料跑一个小任务，再换成你自己的页面。

## 1. 准备页面

[打开练习资料](/practice/shipping-reply-zh.html)。资料均为虚构，不含真实客户信息。

![客户催物流，怎么解释当前进度：中文练习页面](/images/tutorials/shipping-reply-zh.jpg)

截图展示的是任务输入资料，不是 Dassi 的运行结果。

还没安装？先看[Edge 安装图解](/zh/edge-install/)或[Chrome 安装指南](/zh/getting-started/installation/)。打开 Dassi 侧边栏并完成登录；如果提示额度或模型配置，按[模型设置指南](/zh/guides/connect-ai-provider/)完成设置。

## 2. 复制这段 prompt

保持练习页面为当前标签页，把下面的内容粘贴到 Dassi 并发送。

```text
只读取当前练习订单和物流记录，写一段中文客户回复，再给英文版本。包含最近一次扫描的日期和状态，明确暂时没有预计送达时间。不要保证周五到货，不推断丢件，不编造承运商联系结果。给我一条需要人工核对的下一步。只显示草稿，不发送、不修改订单。
```

## 3. 核对结果

核对扫描时间和状态；不能把历史扫描当成实时定位，也不能承诺到货日。

若页面打不开或读取不完整，让 Dassi 说明缺少哪些资料，再补充；不要让它猜测。

## 4. 换成你的业务

打开你有权处理的相关业务页面，修改 prompt 中的产品、数量或语言。先检查一次草稿或表格，再决定下一步。这篇教程不会设置后台自动回复，也不会自动发送客户消息。
