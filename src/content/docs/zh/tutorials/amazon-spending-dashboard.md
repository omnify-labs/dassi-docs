Amazon 一次只显示一单，从不给你算总数。dassi 可以读取你已登录的订单历史并加总——不用导出，也不用把账号密码交给第三方应用。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里登录 Amazon，打开 **Returns & Orders**，把时间筛选设为你关心的范围（比如去年）。旁边打开 dassi。先从一页订单开始；第一遍结果对了再翻页。

## 1. 先算一页

```text
读取本页可见的订单。每一单给出日期、商品和页面显示币种的订单总额。
然后加总：本页合计、按月合计，以及 25 美元以下的订单数量和它们的合计金额。
只读取——不要打开商品页、不要重新下单、不要改任何东西。订单总额看不到就写「未显示」，不要估算。
```

## 2. 翻页继续

```text
继续读取后面几页的订单历史，直到 [月份/年份] 为止。维护一张累计表和一个累计总额；告诉我你读了几页。
如果某一页加载失败或布局变了，停下来告诉我。
```

## 检查结果

抽查三单和页面对一下——一单大额、一单小额、一单不同月份的。dassi 绝不该编造订单金额；「未显示」比猜测好。类别标签是 dassi 根据商品名推断的，当作粗略划分，不是记账。
