:::note[先从小范围开始]
这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

五十条招聘信息，每条把薪资和远程政策藏在不同的段落里。dassi 读一遍，给每一条同样的五列。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开职位搜索结果页（LinkedIn、Indeed、公司招聘页）。旁边打开 dassi。先从一页可见的职位开始。

## 1. 整理屏幕上的

```text
读取本页的招聘信息。每一条给出：职位、公司、地点、远程政策（远程 / 混合 / 现场 / 未说明）、薪资范围原文（或「未说明」）、要求的经验年限，以及提到的 3 项主要技能。
只从职位文字里读；宁可写「未说明」也不要推断。不要打开职位，不要申请任何东西。
```

## 2. 筛候选

```text
从那张表里，隐藏要求超过 [N] 年或必须现场办公的。剩下的按与 [我的技术栈 / 我的优先级] 的匹配度排序，每条用一行解释排序原因。
```

## 检查结果

打开候选名单里的两条，把薪资和年限字段和职位原文对一下——这两个字段各网站格式最不一致。「未说明」应该很常见；如果 dassi 填满了每一格，那它在猜。这张表只是一页的快照；重复第 1 步来翻页。
