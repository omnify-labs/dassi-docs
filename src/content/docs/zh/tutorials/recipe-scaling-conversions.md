四人份的菜谱做七个人吃，意味着站在灶台前做算术。dassi 在页面上算一次，并保留原始数量供对照。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开菜谱，滚动到食材列表。旁边打开 dassi。

## 1. 换算份数和单位

```text
找到本页的食材列表。把它从 [原份数] 换算到 [目标份数]，并把每个数量都换成公制（克、毫升）。原始数量和新数量并排显示。
四舍五入到厨房里合理的量，并说明哪些换算取决于密度（比如一杯面粉 vs. 一杯糖）。
```

## 2. 替代食材和购物清单

```text
给 [食材] 建议一个 [无乳制品 / 纯素 / 我手头有的] 的替代品。然后给我一份按货架分组的购物清单，数量按换算后的菜谱。
```

## 检查结果

手动核对一种食材（原量 × 7/4）。注意鸡蛋这类不能线性换算的东西——dassi 应该取整，而不是让你用 3.5 个鸡蛋。替代品只是建议；除非你要求，烹饪时间不会被换算。
