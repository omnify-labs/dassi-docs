「我合适吗？」这个问题，你是靠把要求列表读两遍来回答的。dassi 读一遍，对着你真实的简历，并展示它的依据。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开招聘信息。在另一个标签页打开你的简历，或把它加为[文件引用](/zh/guides/file-references/)。在招聘信息标签页上打开 dassi。

## 1. 打匹配分

```text
把这条招聘信息和我在「[简历标签页 / 引用名]」里的简历做对比。列出招聘信息里的每一条要求，逐条标注：满足（引用简历原句）、部分满足、缺口。总体匹配写成「Y 条要求满足 X 条」——不要百分比。
不要编造我没有的经历。
```

## 2. 决定怎么说

```text
对于部分满足和缺口的项目，告诉我哪些可能是硬门槛、哪些可以培养。然后用 3 条要点重写我的简历摘要，优先突出我满足得最好的要求，只用简历里已有的事实。
```

## 检查结果

每个「满足」都应该引用简历里的真实一句；抽查两条。硬门槛的判断是 dassi 对雇主的猜测——当作再读一遍招聘信息的提醒，不是决定。招聘网站上不应该有任何改动；dassi 在这里不会替你申请或保存。
