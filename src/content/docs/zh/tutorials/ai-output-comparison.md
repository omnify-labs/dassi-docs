比较两个聊天机器人通常意味着把两个答案复制到第三个窗口。dassi 直接读它们所在的两个标签页。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在同一个 Chrome 窗口的两个标签页里，用两个工具（比如 ChatGPT 和 Claude）跑同一个提示。让两个答案都留在屏幕上。在任一标签页打开 dassi。问之前先想好「更好」对你意味着什么——回复率、准确性、语气。

## 1. 比较

```text
读我 ChatGPT 标签页里最新的回答和 Claude 标签页里最新的回答。两者的提示都是：「[提示]」。我的目标是 [「更好」的含义，比如一封能收到回复的销售邮件]。
从这几方面比较：是否贴合目标、事实准确性、长度、语气。给出结论和 3 条具体理由，分别引用两个回答的原文。
```

## 2. 改进提示

```text
写一个修改版提示，保留两个回答的优点，修正你发现的缺点。每处修改用一行解释。不要运行——我自己粘贴。
```

## 检查结果

比较里的引用应该能在标签页里找到——每边查一条。结论里如果没有你的目标，那就是泛泛之谈；如果读起来是这样，重申目标再问一次。dassi 在这里不会向任何一个工具发送内容。
