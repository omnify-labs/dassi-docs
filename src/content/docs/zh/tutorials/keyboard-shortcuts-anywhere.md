这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

审核队列、工单列表、后台表格：同样的点击-滚动-点击一天一百次。dassi 可以给页面加键盘导航，而且它知道不要把键绑到红色按钮上。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开你反复使用的列表视图。旁边打开 dassi。要让快捷键跨访问保留，满意之后让 dassi 把它保存为[持久脚本](/zh/guides/user-scripts/)。

## 1. 加导航

```text
本页有一个 [工单 / 行 / 卡片] 列表。加上键盘导航：J 把高亮往下移，K 往上移，Enter 打开高亮的项目。告诉我你把哪个元素当作列表。
不要把任何键绑到删除、发送、批准或提交的操作上。
```

## 2. 加一个安全操作，然后保留

```text
再把 Shift+R 绑到打开高亮项目的 [备注 / 详情] 面板。然后把这个保存为 [URL 模式] 的持久脚本，让我每次打开这个视图时它都运行。
```

## 检查结果

按 J 五次再按 Enter：应该打开正确的项目。光标在文本框里时试试快捷键——它们不应该触发。检查保存的脚本的 URL 模式没有比你想要的视图更宽。如果它行为不对，让 dassi 列出或删除脚本。
