这是一个工作流的提示模板，不是经过验证的案例。结果取决于网站、你打开的页面和模型。行动之前先检查输出；任何会改变账号状态的操作（提交、发送、预订、购买）留给你自己来做。
:::

周一的更新每周都一样：看面板、挑出变化、写三句话。dassi 读的是你屏幕上的视图——包括任何集成都看不到的自定义面板。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开数据面板，把日期范围设为上周（如果工具支持，和前一周对比）。滚动到你要汇报的指标可见。旁边打开 dassi。

## 1. 起草周报

```text
读取本面板在所选周期内可见的指标。为 [Slack / 邮件] 写一段 120 字以内的周报：整体流量变化、前 3 个页面、涨跌最大的一项。
只用页面上显示的数字，并原样引用。如果对比周期不可见，就说明这一点，不要估算变化。
只读取——不要改筛选条件、日期范围或面板设置。
```

## 2. 加上「所以呢」

```text
再加一句话说明最大变化最可能的原因，明确标注为推测；再加一条本周建议采取的行动。
```

## 检查结果

草稿里的每个数字都应该能在屏幕上找到；检查两三个你会被问到的。如果 dassi 在面板里滚动或切换了标签页，确认日期范围没变。推测那句话是观点——发送前改掉或删掉。
