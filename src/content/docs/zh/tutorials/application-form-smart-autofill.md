浏览器自动填充靠匹配字段名；它不知道「最近雇主」和「当前公司」是同一个问题。dassi 读标签、读简历，按含义填。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开申请表。在另一个标签页打开你的简历（Google 文档、PDF 或 LinkedIn 个人页），或者把它加为[文件引用](/zh/guides/file-references/)。在表单标签页上打开 dassi。

## 1. 填当前页

```text
用我在标签页「[简历标签页名]」里的简历填写本页的申请字段。按含义匹配字段，不只看标签。用表单要求的日期格式。
以下内容留空并列给我：简历里没有的信息、任何关于资格或法律身份的是/否问题、任何自由文本问题。不要点 Next 或 Submit。
```

## 2. 补上剩下的

```text
空着的字段答案如下：[字段 → 值，…]。填进去。然后把本页每个字段和你填的值列出来，我检查完再自己点 Next。
```

## 检查结果

对着表单读一遍字段列表——日期和电话格式是自动填充最容易出错的地方。确认没有提交：页面应该还是你开始时那一页。多页表单：每页重复第 1 步；每次由你点 **Next**。
