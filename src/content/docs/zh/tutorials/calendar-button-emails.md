「周四三点，第五大道的 Blue Bottle？」就是一条用散文写的日历事件。dassi 读会话、理出细节、起草事件——你来确认。

## 开始之前

第一次用 dassi？先看[安装指南](/zh/getting-started/installation/)和[模型设置指南](/zh/guides/connect-ai-provider/)。

在 Chrome 里打开邮件会话，在另一个标签页打开你的日历（Google 日历、Outlook）。在邮件标签页上打开 dassi。

## 1. 提取细节

```text
读这个邮件会话，提取会面细节：日期、开始时间、提到的时区、时长、地点或视频链接、参与者。以列表显示给我，并说明哪些是你推断的（比如时长）而不是读到的。
先不要创建任何东西。
```

## 2. 创建事件

```text
都对，除了 [更正]。切换到我的日历标签页，用这些细节创建事件，标题用邮件主题。保存后把已保存事件的日期、时间和地点显示给我。
```

## 检查结果

在日历里打开事件，和邮件对一遍——没写日期的「周四」是推断最容易错的地方，时区是第二常见的失误。确认没有给参与者发邀请，除非你要求了。
